# JARVIS 5.24 Premium Assistant

Обновление поверх установленной версии: `applicationId` и release signing key сохранены. `versionCode=28` выше 5.23 (`27`), поэтому Android должен принять APK как обновление без удаления приложения, если APK подписан тем же ключом.

## Что исправлено
- Полностью переработан главный экран: компактная иерархия, нормальные размеры шрифта, центрирование текста внутри кнопок, без растянутых/сплющенных элементов.
- Нижняя строка ввода стала шире и выше; кнопка отправки имеет ту же высоту. При открытии клавиатуры composer автоматически поднимается над IME, после закрытия возвращается вниз.
- Убраны быстрые кнопки с главного экрана.
- Настройки переработаны в компактные карточки; длинные надписи больше не растягивают кнопки.
- Исправлен аварийный путь открытия SettingsActivity: убраны небезопасные динамические/null-вставки и оставлены конкретные системные Intent-назначения. TTS открывается через `android.settings.TTS_SETTINGS` с fallback.
- Исправлены UI-обновления из фоновых потоков: ответы web/search и состояние движка проходят через main thread. Это устраняет типичный `Only the original thread that created a view hierarchy can touch its views`.
- `JarvisEngine.handle()` получил верхнеуровневый safety boundary: неизвестная/сломавшаяся команда больше не должна валить приложение.
- Обычные разговорные фразы больше не отправляются автоматически в веб-поиск. Добавлены локальные ответы для короткого диалога.
- Музыка: запоминается выбранное музыкальное приложение; добавлены актуальные пакеты Яндекс Музыки (`ru.yandex.music`) и VK Музыки (`com.uma.musicvk`), поиск трека/плейлиста открывается через приложение, после запуска выполняется системная команда Play как best-effort.
- Для «моя музыка / понравившиеся / любимые» JARVIS пытается продолжить воспроизведение через системный media control. Универсального Android API для выбора приватного плейлиста чужого приложения нет, поэтому приложение не притворяется, что гарантированно управляет внутренним каталогом.
- «Плейлист <название>» открывает поиск соответствующего плейлиста в выбранном музыкальном сервисе.
- Release version: `5.24.0-premium-jarvis`, versionCode `28`.

## Важное ограничение голосового вызова
Фраза «Привет, Джарвис» реализована через foreground microphone service и Android SpeechRecognizer. На современных версиях Android фоновые микрофоны могут быть ограничены самой ОС. Самый надёжный системный путь — назначить JARVIS системным помощником Android. Приложение не выдаёт ложный статус «всегда слушаю», если ОС остановила сервис.

## Сборка
GitHub Actions workflow использует Gradle 8.11.1 и выполняет:
`gradle --no-daemon --stacktrace :app:assembleRelease`

После сборки workflow проверяет наличие APK и целостность ZIP/APK.
