# JARVIS 5.9.0 Professional HUD

## Что изменено
- `versionCode 13`, `versionName 5.9.0-professional-hud`: установка поверх предыдущей версии определяется Android как обновление при сохранении `applicationId`.
- Полностью переработана главная композиция: безопасные отступы от status bar, единая сетка, центральное ядро, ответ, строка запроса, единый ряд «ГОВОРИТЬ / СТОП», быстрые команды и нижняя HUD-навигация.
- Экран настроек приведён к тому же чёрно-синему HUD-языку.
- Кнопка ядра и «ГОВОРИТЬ» запускают распознавание речи с корректной проверкой разрешения микрофона.
- После выдачи разрешения микрофона фоновый вызов «Джарвис» включается по умолчанию; когда приложение уходит в фон, foreground microphone service начинает ожидание wake word. При возврате в приложение сервис останавливается, чтобы не конкурировать с экранным распознаванием.
- Wake-word сервис использует короткие окна SpeechRecognizer, partial results, on-device recognition при наличии и автоматический перезапуск.
- Исправлен `RemoteException` в `JarvisRecognitionService`.
- Таймер больше не является `Handler`-заглушкой: сначала используется системный `AlarmClock.ACTION_SET_TIMER`, при отсутствии подходящего приложения — реальный `AlarmManager`, который переживает завершение процесса JARVIS.
- Будильник также использует `AlarmManager` и проверяет разрешение точных будильников.
- Сохранены команды времени, даты, батареи, фонарика, громкости, калькулятора, памяти, камеры, системных настроек, звонка/SMS и web-поиска.

## Важное ограничение Android
Фоновое распознавание wake word не может быть гарантировано одинаково на всех устройствах: Android и оболочки производителей могут ограничивать микрофон, автозапуск и работу foreground services. JARVIS не маскирует это ограничение и показывает состояние в настройках.
