# JARVIS Home Multitool v4 — Lock Screen Assistant

Голосовой домашний мультитул JARVIS с интеграцией в системный VoiceInteractionService Android.

## Вызов с заблокированного телефона
После установки откройте JARVIS → **🔐 Экран блокировки** и подтвердите выбор JARVIS как системного ассистента.
После этого Android может запускать JARVIS через системный жест/кнопку ассистента даже при активном экране блокировки. JARVIS использует `VoiceInteractionService` и отдельный `VoiceInteractionSessionService`, а при вызове с Keyguard открывает свой интерфейс поверх экрана блокировки и автоматически начинает слушать команду.

Важно: Android и оболочка производителя сами определяют доступный способ вызова ассистента (например, жест или удержание кнопки питания). Полностью произвольное постоянное прослушивание фразы «Джарвис» сторонним приложением без системной поддержки hotword на всех устройствах гарантировать нельзя.

## Голос
Глубокий мужской профиль TTS, низкий pitch, спокойная подача. Фактический голос зависит от установленного TTS-движка устройства.
